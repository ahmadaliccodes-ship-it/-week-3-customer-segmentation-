## Features and Usage

| Feature | Meaning | Project usage |
|---|---|---|
| Fresh | Annual spending on fresh products | Clustering feature |
| Milk | Annual spending on milk products | Clustering feature |
| Grocery | Annual grocery spending | Clustering feature |
| Frozen | Annual frozen-product spending | Clustering feature |
| Detergents_Paper | Annual spending on detergents and paper products | Clustering feature |
| Delicassen | Annual spending on delicatessen products | Clustering feature |
| Channel | Customer sales channel | Contextual analysis |
| Region | Customer region | Contextual analysis |

Channel and Region are used for contextual analysis.
The six annual spending variables are used as clustering features.

## Generated Files

The following files are generated by the project pipeline and are not source data:

- `data/processed/scaled_features.csv` — log-transformed and standardized clustering features.
- `data/processed/labeled_customers.csv` — customer records with final cluster labels.
- `data/processed/stability_summary.csv` — clustering stability validation summary.
- `data/processed/k_selection.json` — canonical final K-selection decision and supporting metrics.

Figures generated by the notebooks are stored under `figures/`.
Report artifacts generated by the pipeline are stored under `reports/`.
